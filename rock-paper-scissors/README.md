# 🎮 Rock Paper Scissors

A simple command-line Rock Paper Scissors game built with Python. Play against the computer, which randomly chooses Rock, Paper, or Scissors.

## Features

* Player vs. computer gameplay
* Random computer choices
* Input validation
* Win, loss, and tie tracking
* Play multiple rounds

## Requirements

* Python 3
* No external dependencies

## Usage

Run the game:

```bash
python rock-paper-scissor.py
```

## How to Play

Choose one of the following:

* `r` → Rock
* `p` → Paper
* `s` → Scissors

### Rules

* Rock beats Scissors
* Scissors beats Paper
* Paper beats Rock
* Same choices result in a tie

After each round, choose:

* `y` → Continue
* `n` → Quit
