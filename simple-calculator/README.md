# Simple Calculator

A command-line calculator built with Python for common arithmetic and mathematical operations.

## Features

- Addition
- Subtraction
- Multiplication
- Division with division-by-zero handling
- Average
- Modulus with division-by-zero handling
- Power
- Square root with negative-input validation
- Square
- Cube
- Interactive CLI menu
- Numeric input validation

## Requirements

- Python 3.x
- No external dependencies

## Usage

```bash
python calculator.py
